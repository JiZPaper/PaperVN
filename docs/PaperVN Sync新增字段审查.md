### 2. PaperVN Sync 状态（应用支持目录 `PaperVN Sync/〔所有者〕.json`，本次）

`同步状态存储`

| 字段 | 类型 | 说明 |
|---|---|---|
| 基线 | [资料库平台: 平台基线] | 各平台上次同步完成时的状态 |
| 待推送 | [PaperVN ID: Set<资料库平台>] | 在 PaperVN 中做的、还没推送成功的修改 |
| 隐藏 | [PaperVN ID: Set<资料库平台>] | 分别保留时隐藏的作品，以及它们所在的平台 |
| 隐藏条目 | [PaperVN ID: 本地资料库条目] | 隐藏时的记录，重新显示时加回资料库 |

`平台基线`：账户ID（String）、账户名称（String）、快照（[PaperVN ID: 同步快照]）

`同步快照`：状态（资料库状态）、评分（Int?，10–100）、进度（Int?）

### 3. 只在内存里的结构（不保存，本次）

- `同步会话` 新增“无法删除”：平台不支持删除、需要用户手动删除的作品（本次）
- `同步能力` 新增“支持删除”（本次）
- `平台资料库记录`、`条目冲突` 新增“多语言标题”（本次）
- `同步会话` 新增“修改时间来源”：第一次导入时用户选的平台；只有一个平台提供更改时间时自动使用它（本次）

**多语言标题的来源**（本次）：AniList 原名＋出品国家决定语言、罗马字、英文；MAL 原名（alternative_titles.ja）、罗马字（title）、英文；Annict 原名、罗马字、英文；Bangumi 原名、简体中文。各平台的英文标题视为官方；**Bangumi 的中文名视为非官方**，要打开“允许非官方标题”才会显示。

- `平台资料库记录`：平台、平台ID、类型、malID、标题、日文标题、封面地址、快照、总数、平均评分、发行日期、开始日期、完成日期、修改时间
- `同步会话`：本地、平台、基线、待推送、减少提示、减少处理、需要选择导入方式、来源概况、导入方式、冲突、结果、推送、未匹配、新隐藏、读取失败、查找到的ID，以及几个步骤标记
- `条目冲突`：种类（外部更改／记录不同）、键、标题、类型、封面地址、版本、选择
- `导入方式`：合并／为准（来源）／分别保留（来源）
- `减少处理`：保留并重新上传／同样删除

## 三、需要确认的做法

1. **分别保留**：所选资料库里也有、但记录不同的作品，会以所选的为准，并同步到其他账户。如果你希望这些作品在其他账户上也保持原样，需要再改。
2. **不采用其他平台上的更改**：会把该平台改回资料库的记录。不采用平台上的新增，就会从该平台删除那部作品。
3. **“作品数量减少”的判断**：平台从有作品变成 0 部；或者比上次少了 20 部以上、并且少了一半以上。
4. **合并新账户时**：只在新账户里有的作品直接加入，不逐项询问，因为选择“合并”已经表示同意。记录不同的作品逐项询问。
5. **显示已隐藏的作品**：算作在 PaperVN 中做的修改，会直接同步到其他平台。如果隐藏期间平台上的记录有改动，会出现在“检查更改”里。
